# CodeAlpha Frontend Development Internship Tasks

This repository contains all the completed frontend development tasks
for the CodeAlpha Internship Program.  
Each task is organized in a separate folder with its own source code
and documentation.

---

## Task 1: Image Gallery

A modern single-image gallery built using HTML, CSS, and JavaScript.
The gallery displays one image at a time with smooth next and previous
navigation.

### Features
- Single image display
- Next & Previous navigation buttons
- Responsive layout
- Clean and minimal UI
- JavaScript-based image switching

 Folder: `Task-1_Image-Gallery`

---

## Task 2: Calculator

A functional calculator application developed using HTML, CSS, and
JavaScript. It supports all basic arithmetic operations with a
user-friendly interface.

### Features
- Addition, subtraction, multiplication, and division
- Clear display functionality
- Real-time result calculation
- Simple and clean UI

 Folder: `Task-2_Calculator`

---

## Task 3: Portfolio Website

A modern and responsive personal portfolio website designed to
showcase frontend development skills, projects, and technologies.

### Features
- Professional UI layout
- Responsive design using Flexbox & Grid
- Projects showcase section
- Skills section
- Clean typography and spacing

 Folder: `Task-3_Portfolio`
